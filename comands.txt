
   ////////////////////////////////////
  // Pasos para publicar en gitHub: //
 ////////////////////////////////////

1- git init
2- git remote add origin https://github.com/CarlosMC87/ProyectoAcademia.git
3- git add .
4- git commit -m "Estructura de carpetas para proyecto AL ProyectoAcademia"
5- git branch -M main

Si no sube, al ser el caso de un proyecto nuevo podemos forzar.
6- git push -u origin main
6- git push -u origin main --force 

  //////////////////////////////////////////
 // Para eliminar el repositorio de git: //
//////////////////////////////////////////

1- Remove-Item -Recurse -Force .git
